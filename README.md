# Aprendendo-HTML-E-criando-um-site-Descrevendo-um-super-vilao-Atividade-do-SENAI_RS-

Esse primeiro site foi realizado por Arthur Santos Lopes e Gabriel Heineck Haberkamp, alunos do SENAI-RS do curso programador Full-Stack Jovem Aprendiz, no dia 06/10/2026, esse site tem compatibilidade com leitor de tela NVDA, sendo acessível para pessoas de baixa visão/deficiência visual

##

Para executar o programa, basta baixar o projeto apertando o botão verde chamado ***<>code***, depois ***Download ZIP*** (que irá fazer uma instalação em arquivo **.zip**), após isso, fazer a extração do arquivo através do Windows Explorer ou utilizar o programa WinRAR.

##

Por fim, é necessário fazer a instalação da extensão "Live Server" através do Microsoft Visual Studio Code, para poder executar o Site.
